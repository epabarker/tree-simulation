# M16: calibrating storms

## Question
What σ_break and storm load make storms visibly reshape the home page's forest (limbs lost, the odd tree thrown, gaps that refill) without stripping it? Do calm seasons stay unbroken?

## Setup
The `forest` preset (ring of 210 cells, O4) with `o2.stormP` 0.05, for 300 seasons, seeds 1–3, sweeping σ_break ∈ {3500, 4500, 6000} and `stormLoad` ∈ {1, 1.5, 3}. For each run I counted:
- metamers broken per storm;
- breaks in calm seasons;
- trees thrown;
- live trees and the tallest height at the end.

The script ran ad hoc in the session; the same loop is the `storms.test.ts` check.

## Result
| σ_break | load | metamers broken per storm | calm-season breaks | trees thrown (3 × 300 seasons) |
|---|---|---|---|---|
| 3500 | 1.5 | 239 | 0 | 0 |
| 3500 | 3 | 399 | 0 | 0 |
| 4500 | 1 | 72 | 0 | 12 |
| **4500** | **1.5** | **137** | **0** | **17** |
| 6000 | 1.5 | 45 | 0 | 0 |

The thrown counts for 4500 come from the final windthrow rule, 0.06·load·(H/100)². A first rule, which based windthrow on the trunk base's stress, almost never fired, because the pipe model makes bases thick.

**Chosen:** σ_break 4500 and load 1.5. A storm takes about 7% of the forest's metamers, mostly exposed upper limbs, and throws a tree every two or three storms, so a storm opens a new gap about every 50 seasons. Calm seasons never break.

## Conclusion
Storms now make R3's breakage do something, and they give the home page a rare, visible event: a gale, falling limbs, and the occasional tree toppling into the plate. Whether storms also raise bimodality in self-thinning (the M11 marginal result) is left for M20, with species, since some species are more brittle.
