# M22: the §8 ablations

## Question
Switch off one rule at a time. Does the change the spec predicts (§8) appear, against the same runs with every rule on?

Six ablations had no test or only a partial one. Pooled light also needed a new mode, `c2.model: "pooled"` (`light/pooled.ts`). In it, every leaf gets the mean light of one homogeneous canopy, C·(1 − e^(−kL))/(kL), with L the stand's leaf-area index. A tree's light is then in proportion to its leaf area: size-symmetric competition (Weiner 1990).

## Setup
- **Tests:** `src/core/ablation.test.ts`, about 16 s, run by `npm run check`.
- **Probes:** the values below were measured with throwaway test files at the same settings (seeds 1–5 unless stated).

## Where the model departs from the spec's predictions

**ξ = 0.**
- **What the spec expects:** it reads Palubicki's Fig. 12 as "crowns ignore gaps and neighbours" without phototropism.
- **What happens here:** crowns lean into gaps by three routes:
  - shoot direction (ξ);
  - Borchert–Honda allocation, which feeds the well-lit side;
  - C5 shedding, which removes the shaded side.
  Only the first stops at ξ = 0, so the lean barely changes in a stand.
- **Where ξ does show:** under an oblique sun its share is about a fifth of the crown's offset.
- **The test** checks what ξ does: shoots turn less to the light, while the crown still leans.

**R4 off.**
- **What the spec expects:** slower gap refill, as if reiteration were the only way back into a gap.
- **Why the comparison doesn't show it:** the R4-off baseline is *more* permissive than R4. Without it, any live bud with resource v ≥ 1 grows, and no dormant bud ever needs releasing, so gaps fill at least as fast.
- **What R4 adds:** a bank of dormant buds (about 120 a tree), released by light after a disturbance, and the epicormic flush on old trunks (`release.test.ts`).
- **The test** checks those.

**Pooled light and bimodality.**
- **The spec's prediction:** pooled light removes bimodality.
- **Why it can't be tested:** the directional stand is not clearly bimodal either. Its bimodality coefficient is 0.38–0.44, below the 0.555 threshold (STATUS known issues). And with near-identical trees under pooled light, the coefficient is meaningless.
- **The test** checks the size inequality, and that nothing is suppressed.

## Conclusion
- **Tested now:** all eleven §8 ablations, six of them in this milestone.
- **As predicted:** four match the spec outright (C3 equal sharing, R1, R6, pooled light).
- **Departures:** two depart for reasons the model makes explicit (ξ, R4), and the tests assert what each rule actually does.
- **Follow-up:** amend the spec's §8 table with these two results, if the user agrees.
