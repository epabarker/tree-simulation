# Woodland Trust Ancient Tree Inventory (audit, 2026-11-03)

- **Link:** https://ati.woodlandtrust.org.uk/ resolves; > 190,000 trees listed (home page).
- **Licence: none open.** Site terms: personal non-commercial use of extracts only; "No other use … without
  first obtaining our written permission"; footer "Images © protected Woodland Trust". No dataset licence found.
- **Bulk data:** "The Ancient Tree Inventory dataset is available upon request" (reports/current-research).
  No CSV, portal or API found; the NBN Atlas registry search 404s. **Nothing downloaded.**
- **Fields:** girth (measured), veteran status, tree form (maiden, pollard, coppice, multi-stem: recording guide);
  **no height or crown spread** on result pages. Recording form PDF not machine-readable.
- **Per-species counts: unverifiable.** Only the 2019 summary's percentages: oak 40% of all trees, beech 13%,
  sycamore 3%, field maple 1%; of ancient trees oak 44%, beech 5%, field maple 3%. Birch, hornbeam, willow,
  rowan, holly, pine, fir: not documented.

**Use:** at most a manual reference for veteran forms (pollards, multi-stems), viewed not reused, and only with
the Trust's written permission for anything beyond that. Biased to veterans, which the garden does not grow.
Not a target source for any level.
