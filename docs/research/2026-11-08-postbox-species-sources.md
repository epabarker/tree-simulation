# Post-box sycamore and ash sources

2026-11-08. Targets are registered before tuning in the day3 plan, step8b.
Separate species: sycamore (*Acer pseudoplatanus*) and common ash (*Fraxinus excelsior*).
Field maple (*Acer campestre*) is retained. No new species is adopted by this note.

Matched-size height/crown-radius targets will use the local Tallo dataset and the
existing regional filter, quantile curves and real-tree control. Exact numeric
summaries, coverage, input hashes and candidate priors must be frozen before runs.
No per-tree reference tables belong in this note.

Primary descriptive context checked2026-11-08:

- [Forest Research, sycamore](https://www.forestresearch.gov.uk/tools-and-resources/tree-species-database/131555-sycamore-sy-2/): a large tree exceeding30m.
- [Forestry England, sycamore](https://www.forestryengland.uk/article/sycamore): can reach35m.
- [Kew, Fraxinus excelsior](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:609009-1/general-information): species description allows heights to40m.
- [Thomas2016, Biological Flora of the British Isles: Fraxinus excelsior](https://besjournals.onlinelibrary.wiley.com/doi/full/10.1111/1365-2745.12566): common lowland heights20–25m, richer alluvial sites40–45m. Site context matters; maxima are not median targets.

The initial maturity calculation is an inference from the registered source
height and the existing strong reproductive-sink relationship, not a measured
species parameter. Generic opposite-branching maple physiology is only a starting
prior. Source-target, fresh-seed and garden gates must test each candidate.
